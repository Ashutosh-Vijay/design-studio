# Changelog

New work collects under Unreleased and moves into a version when it ships. The same notes are in the app (About, What's new).

## 0.1.0 (October 2026): the first beta

- **Design Center specs, fast**: open RAML and OAS projects of any size in seconds. Every edit is checked by AMF, the engine Design Center uses, so errors show as you type. Suggestions for types, traits and `!include` paths are instant, and Design Center's shelf sits under the editor.
- **Forms and code in step**: build a new API from the forms, as with Design Center's Guide me through it, or edit any spec with them: resources, methods, types, parameters, security schemes and responses for RAML 1.0 and OAS 3.0. Switch between forms and code any time, and a form changes only the lines it must. Or start from a secured starter that passes MuleSoft's best-practice and OWASP security rulesets. Rename a type everywhere, find its uses, extract to a library, or delete with cascade.
- **Design Center and Exchange**: sign in with Anypoint, pull your projects, push with the branch lock, work on branches and merge with conflict help. Publish to Exchange with a suggested version, manage Exchange dependencies, and see what changed since the last version. Connections start read only.
- **Governance, docs and a local mock**: check your API against the rulesets it depends on, read it as documentation, try any method on a local mock that answers like Design Center's, and see every type's uses on the API map.
- **AI tools**: Copilot's agent mode can use Design Studio's tools directly, with nothing to set up: open projects, edit specs, run AMF's checks and governance, try the mock and work with Design Center, while you watch every change. Claude Code, Cursor and other agents can connect too, over MCP.
- **API Design Academy**: 46 lessons, from how computers talk (HTTP, JSON, integration, MuleSoft) to all of RAML (types, resource types, traits, security schemes, fragments, libraries), Design Center, Exchange, APIkit and API Manager, with exam-style practice for the MuleSoft Developer I and II certifications. Every lesson has something to try or answer, and AMF checks what you write.
